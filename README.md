## 🚀 Projetos

### 📋 Formulário de Inscrição — Trilhas Inova

Projeto desenvolvido durante o **Desafio 3 da Trilha de Front-End do programa Trilhas Inova**.

O projeto foi desenvolvido de forma colaborativa, utilizando **HTML, CSS e JavaScript**, com foco em uma página de inscrição funcional, responsiva e interativa.

Entre os recursos implementados estão:

* Validação de campos;
* Máscaras para CPF, telefone e CEP;
* Preenchimento automático de endereço via CEP;
* Upload de documentos;
* Armazenamento de dados com `localStorage`;
* Geração de PDF.
